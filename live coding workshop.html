Getting started

Click into a code block, then press Ctrl+Enter (or Cmd+Enter on Mac) to play. Press Ctrl+. to stop.

Samples load from the internet the first time you play them, so the first run can be silent for a few seconds. Try again if you hear nothing.

Refresh the page to get the original worksheet back. When you are ready for more room, open the full editor at strudel.cc.

Basics

sound tells Strudel what to play. The names inside the quotes are the sounds. bd is a bass drum, sd a snare, hh a hi-hat, cp a clap.

Strudel fits everything you write into one repeating loop, called a cycle. Add more sounds and each one gets shorter, so the pattern speeds up.

To play several patterns at once, start each one with $: on its own line.

Exercise 1

Write your own drum pattern with two or three sounds. Then change how many steps it has and notice how the feel changes.

Other sounds to try: oh rim lt mt ht insect wind jazz metal casio

Mini-notation

The text inside the quotes has its own small set of rules, called mini-notation. These are the main ones.

SymbolWhat it doesExample
*Repeat fasterhh*4
/Stretch over more cyclesbd sd/2
~Rest (silence)bd ~ sd ~
[ ]Squeeze steps into one slotbd [sd sd]
< >One step per cycle, alternating<bd cp> hh
,Play at the same time[bd, hh*4]

Notes, scales and chords

For melodies, use note with note names. The number is the octave, so c3 is lower than c4. Add # for sharp or b for flat, as in f#3 or eb3.

Scales

Scales keep you in key. With n and scale, you write numbers (steps of the scale) and every number sounds good together. Try swapping minor for major.

Chords

Notes inside square brackets separated by commas play together. This is how you write a chord.

Effects

Add effects by chaining them onto a pattern with a dot. Each one takes a number, or a pattern of numbers.

FunctionWhat it does
.lpf(n)Low-pass filter: lower numbers sound darker and muffled
.hpf(n)High-pass filter: higher numbers sound thinner
.gain(n)Volume (1 is normal)
.pan(n)Stereo position: 0 is left, 1 is right
.room(n)Reverb
.delay(n)Echo
.speed(n)Playback speed and pitch of a sample
.shape(n)Distortion
.vowel("a")Vowel filter, like a voice

Moving an effect over time

A signal like sine gives a smoothly changing value. .range sets its lowest and highest values, and .slow makes it take longer.

Make a short sketch of your own. Don't plan it out: use your ears and react to what you hear. If you like it, delete it and try to recreate the feel. If you get bored of a sound, change it.

Hydra visuals

Hydra is a live-coding language for visuals. It works like Strudel: you chain small functions together and the picture updates when you run it. Press Run (or Ctrl+Enter in the code box) to start.

Examples:

The pattern is always: source, transforms, output

Every Hydra line starts with a source like osc(), noise() or shape(), adds transforms like .rotate(), .kaleid() or .color(), and ends with .out(). Try the five examples above and change one number at a time.

FunctionWhat it does
osc(freq, sync, offset)Stripes. Frequency sets how many.
noise(scale)Smooth random texture
shape(sides, size)A polygon (a circle at high side counts)
.rotate(angle, speed)Spin the image
.kaleid(n)Mirror into n segments
.color(r, g, b)Tint with red, green, blue (0 to 1)
.modulate(source, amount)Warp the image using another one
src(o0)Read the previous frame (feedback)
() => timeUse a function so a value changes over time
