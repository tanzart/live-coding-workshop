Strudel

Live-code music with patterns. Write a line, run it, change it, run it again.

Basics

Drum patterns

s (short for sound) tells Strudel what to play. bd is a bass drum, sd a snare, hh a hi-hat, cp a clap. Everything you write is squeezed into one repeating loop, called a cycle.

Add more sounds and each one gets shorter, so the pattern speeds up. Swap the drum kit with .bank.

Strudel's built-in sounds

Drums to try: bd sd hh oh cp rim lt mt ht. Other sounds: casio jazz metal insect wind piano. Open the Sounds tab on strudel.cc to browse them all.

Most sounds are a bank of samples. Pick one by number with n:

Basic notes

For melodies use note. n (short for note). Letters are note names and the number is the octave (c3 is lower than c4). No music theory needed: change the letters and numbers, and keep what you like.

Self-discovery: Strudel can also do scales and chords. Search the docs for scale to find out how.

Mini-notation

The text inside the quotes has its own small set of rules.

SymbolWhat it doesExample
*Repeat fasterhh*4
/Stretch over more cyclesbd sd/2
~Rest (silence)bd ~ sd ~
[ ]Squeeze steps into one slotbd [sd sd]
< >One step per cycle<bd cp> hh
,Play at the same timebd*2, hh*4
:Pick a sample numbercasio:2
?Play 50% of the timehh*8?
( #1, #2 )Euclidean rhythmbd(3,8)

(3,8) spreads 3 hits as evenly as possible across 8 steps. Change the numbers.

Stacks vs separate $: lines

There are two ways to play several patterns at once. A stack bundles them into one pattern, so an effect on the end applies to all of them.

Separate $: lines are independent tracks. Each one has its own effects, and you can mute one by putting _ in front (_$:) and re-running.

Build a beat with at least four symbols from the table. Then add a second $: track with a note melody. Add one thing at a time and listen after every change.

Synth fundamentals

Every synth sound is built from a simple wave shape. Strudel has four, and the shape decides the character of the sound.

SoundWhat it sounds like
sinePure and smooth, like a soft flute or a sub bass
triangleSoft and roundish - pleasant alarm tones
sawtoothBrassy and bright. The classic synth sound (also works as saw)
squareHollow and angry, sounds like a clarinet

This plays the same notes with each wave in turn, one per cycle. Listen for the difference.

Now all four at once, and a bass line one octave down.

See the wave shape drawn live. ._scope() shows an oscilloscope under the code.

Exercise 2

Layer two different waves on the same notes, one quiet and one loud (.gain). Which combination do you like?

Noise

Noise is random sound with no pitch. It is the raw material for hi-hats, snares, wind and static. Strudel has white (bright hiss), pink (softer) and brown (deep rumble). Turn the volume down first.

Noise plus a short envelope is a drum. .decay sets how fast it fades and .sustain(0) stops it holding on.

Sweep a filter across noise for wind or a riser.

crackle is bursts of tiny clicks, like vinyl. .density controls how many.

Exercise 3

Make a full drum kit from noise only: a hi-hat, a snare and a kick. Hint: short decay for hats, medium for snares, low filter for kicks.

Effects

Chain effects onto a pattern with a dot. Each takes a number or a pattern of numbers.

FunctionWhat it does
.lpf(n)Low-pass filter: lower numbers sound darker and muffled
.hpf(n)High-pass filter: higher numbers sound thinner
.gain(n)Volume (1 is normal)
.pan(n)Stereo position: 0 left, 1 right
.room(n)Reverb
.delay(n)Echo
.speed(n)Playback speed and pitch of a sample
.shape(n)Distortion

A signal like sine gives a smoothly changing value. .range sets the lowest and highest values and .slow stretches it over more cycles.

Exercise 4

Take any sound you made earlier and add two effects. Make one of them move with sine.

Hydra

Live-code visuals. Same idea as Strudel: chain small functions, run, change, run.

Press Run (or Ctrl+Enter in the code box). Try the five examples, changing one number at a time.

The pattern is always source, transforms, output: start with osc(), noise() or shape(), add transforms, and finish with .out().

FunctionWhat it does
osc(freq, sync, offset)Stripes. Frequency sets how many.
noise(scale)Smooth random texture
shape(sides, size)A polygon (a circle at high side counts)
.rotate(angle, speed)Spin the image
.kaleid(n)Mirror into n segments
.color(r, g, b)Tint with red, green, blue (0 to 1)
.modulate(source, amount)Warp the image using another one
src(o0)Read the previous frame (feedback)
a.fft[0] to a.fft[3]How loud the sound is in 4 frequency bands, low to high (needs the microphone)
() => timeA function, so a value changes over time

Exercise 5

Start from Modulation. Change the colours, add a .kaleid(), then make one value move with () => Math.sin(time).

Hydra + Strudel: audio-reactive visuals

Strudel has Hydra built in. Put await initHydra() on the first line of a Strudel block and write Hydra code under it. The visuals draw behind the page.

If you can't see visuals: use the full editor at strudel.cc. Paste a block in, run it, and the visuals draw behind the editor.

Visuals that listen to the sound

This version reads the actual audio through your microphone, so any sound in the room moves the picture (including your speakers). Your browser will ask for microphone permission. a.fft[0] is the strength of the lowest frequencies, from 0 to 1.

Exercise 6

Combine your own beat from earlier with Hydra. Use a.fft[1], a.fft[2] and so on for higher frequencies.
